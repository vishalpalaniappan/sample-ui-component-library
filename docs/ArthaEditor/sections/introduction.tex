The editor component is the main interface in the workbench that enables designs to be created, inspected and modified. It will support the following features:

- Monaco editor for loading text based files with customization based on file extension
- Customization for artha files includes visualization of syntax errors, conclusions of reasoning, primitive definitions etc.
- Graph editor for visualizing narratives from the established meaning (and the conclusions of the reasoning)
- Tab support for switching between selected files
- File browser for selecting files 
- Drag and drop support for moving files between file browser and tabs
- Ability to load multiple tab groups into containers

The goal here is to provide the full visual interface for interfacing with the Artha library. This includes creation, inspection and evolution of the meaning. So in this document, I will establish the formats that the information in the Artha library will contain and then I will connect it with the UI. This means that the specification of the Artha library and this library will move forward together and then I will bring it together in the workbench.
